# Datadog Node.js tracer adapter

Use this adapter when repository inspection detects **Datadog Node.js tracer** and the installed version matches the documented scope.

## Scope

current dd-trace.

## Source

https://docs.datadoghq.com/tracing/trace_collection/dd_libraries/nodejs/

The framework-neutral Node.js skills remain authoritative; this adapter adds Datadog Node.js tracer-specific deployment or observability mechanics.
