# AWS EventBridge SDK v3 adapter

Use this adapter when repository inspection detects **AWS EventBridge SDK v3** and the installed version matches the documented scope.

## Scope

AWS SDK v3.

## Source

https://docs.aws.amazon.com/sdk-for-javascript/v3/developer-guide/javascript_eventbridge_code_examples.html

The framework-neutral Node.js skills remain authoritative; this adapter adds AWS EventBridge SDK v3-specific mechanics.
