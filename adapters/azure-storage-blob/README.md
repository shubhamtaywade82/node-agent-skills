# Azure Storage Blob SDK adapter

Use this adapter when repository inspection detects **Azure Storage Blob SDK** and the installed version matches the documented scope.

## Scope

current @azure/storage-blob.

## Source

https://learn.microsoft.com/en-us/javascript/api/overview/azure/storage-blob-readme

The framework-neutral Node.js skills remain authoritative; this adapter adds Azure Storage Blob SDK-specific mechanics.
