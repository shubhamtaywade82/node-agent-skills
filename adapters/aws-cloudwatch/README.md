# AWS CloudWatch SDK v3 adapter

Use this adapter when repository inspection detects **AWS CloudWatch SDK v3** and the installed version matches the documented scope.

## Scope

AWS SDK JS v3.

## Source

https://docs.aws.amazon.com/sdk-for-javascript/v3/developer-guide/javascript_cloudwatch_code_examples.html

The framework-neutral Node.js skills remain authoritative; this adapter adds AWS CloudWatch SDK v3-specific deployment or observability mechanics.
