# Node.js native test runner adapter

Use this adapter when repository inspection detects **Node.js native test runner** and the installed version matches the documented scope.

## Scope

Node 24.x `node:test`.

## Source

https://nodejs.org/docs/latest-v24.x/api/test.html

The framework-neutral Node.js skills remain authoritative; this adapter adds Node.js native test runner-specific mechanics.
